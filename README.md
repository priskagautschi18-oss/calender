# FriendCal – statisches Grundgerüst

Dieses Verzeichnis enthält den ersten visuellen Prototyp für den gemeinsamen
Freundeskalender.

## Enthalten

- responsive Loginseite
- responsive Hauptseite mit Kalendernavigation
- Seitenleiste für persönliche, Gruppen- und Freundeskalender
- mobile Navigation für Smartphones
- einfache statische Monatsansicht mit Beispieldaten
- Gestaltung angelehnt an das bestehende CV-Projekt

## Vorschau

`index.html` über einen lokalen Webserver öffnen. Die Anmeldung ist im Moment
nur eine Demo-Navigation und wird später durch die REST API ersetzt.

## Technologien

- HTML
- CSS
- JavaScript
